# Edo Sanctuary — Japanese Palace & Sakura Garden 3D

An interactive 3D Japanese Edo castle keep set in a blooming sakura garden, with an arched stream bridge, stone lanterns, an animated koi pond, and a sunset mountain backdrop.

**Live demo:** [https://palaces-eight.vercel.app/](https://palaces-eight.vercel.app/)

## Tech stack

- React 19 + TypeScript
- Three.js
- Vite
- Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```

The dev server starts at http://localhost:3000.

## Build

```bash
npm run build
npm run preview
```
